## Notes

Icons scale per brand by `min(1, ICON_H / source icon height)`, and six distinct factors occur in practice. Do not use a shape-class constant.

Icon layer names are not uniform in the source library: the five `Node/Server` brands use `Rack`, everything else uses `icon`. Each brand's real layer name is recorded as `icon.iconLayerName` in `library-inventory.json`.

The pre-normalization components are preserved on the `Components (legacy)` page and are never modified.
